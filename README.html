HCL Setup Guide (Raspberry Pi)

This folder is ready to use. Do not rename or move files.

First-Time Installation

  1. Open Raspberry Pi File Manager.
  2. Open the luminaire-deploy folder.
  3. Right-click install.sh.
  4. Click Run as Program.
  5. Wait until installation finishes.
  6. Open browser and go to http://localhost/.
If "Run as Program" isn't visible, right-click the file → Properties → Permissions → set Execute to Anyone.

Daily Operations (File Manager)

  • Start app: right-click start.sh → Run as Program
  • Stop app: right-click stop.sh → Run as Program
  • Update app: right-click update.sh → Run as Program

Adding New Scenes

  1. Copy new scene files into luminaire-deploy/scenes/.
  2. Right-click restart.sh → Run as Program.

Important: A restart is required after adding or changing scene files.

Remote Access (Tailscale)

  1. Right-click install_tailscale.sh → Run as Program.
  2. Complete Tailscale sign-in if prompted.

This sets up OpenSSH and a tails user (Default password: tails@rpi).
